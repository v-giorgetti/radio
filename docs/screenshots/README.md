The screenshots show the actual hosted UI with generated sample artwork, synthetic
audio, and simulated station metadata. Counts are illustrative. Capturing these
views does not start or change the server's broadcast.

To refresh them, open the demo URL, wait for fonts and artwork, start demo playback,
and capture the desktop and mobile views. For the EQ view, open the equalizer and
wait for the popup transition to finish before capturing. Keep host credentials,
access codes, and private settings out of screenshots.
